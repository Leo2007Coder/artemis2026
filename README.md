A calm, one-decision-at-a-time planner for a first-time investor. Aarav is 19, earns about ₹8,000 a month, has never invested, and wants to reach ₹10 lakh.
Educational demo only. Returns are illustrative assumptions, not predictions or investment advice.
Repository structure
The repo has three working folders. Each one has a separate purpose.
artemis2026-/
├── app/          React + Vite + TypeScript build (home and investment screens)
├── docs/         PRD, build workflow, and the original problem brief
├── reference/    Complete working prototype (plain HTML, CSS, JavaScript)
├── .gitignore
├── LICENSE
└── README.md
Folder	What it holds
reference/	The complete prototype: index.html, style.css, chatbot.js, theme.js, goal-popups.js
app/	The React version: screens, components, data files, and styles under app/src/
docs/	Honest_Million_PRD_and_Build_Workflow.md and the original brief (.docx)
Run the prototype
No installation is needed.
1.	Open the project in VS Code.
2.	Install the Live Server extension if you don't have it. Search "Live Server" in the Extensions panel.
3.	Right-click reference/index.html and choose Open with Live Server.
4.	Press Ctrl+F5 to load the latest version.
Double-clicking reference/index.html also works, but Live Server saves data and navigates pages more reliably. Fonts load from Google Fonts, so an internet connection gives the intended typefaces.
